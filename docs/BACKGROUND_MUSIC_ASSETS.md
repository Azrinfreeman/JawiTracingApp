## Authorship, method and rights

The loop is original to this project. It was composed as code during the implementation of
[the fullscreen tracing and audio plan](FULLSCREEN_TRACING_AUDIO_IMPLEMENTATION.md): every note,
envelope and mix level is written in the script, and sound is synthesised from sine partials
(soft mallet melody, plucked arpeggio, sine bass, a muted thump and a quiet shaker). It uses no
sample library, downloaded track, external stream, voice, lyric or account connection. The
project owner may use it with the game without a third-party licence. The script is deterministic
(fixed noise seed), so rerunning it with the same encoder reproduces the same decoded audio.

The script needs `numpy` and `lameenc` (`pip install numpy lameenc`). For this render,
`lameenc 1.8.4` was installed outside the repository; it is not a project dependency.

Delay taps wrap around the loop length, so the end of bar 24 flows into the first beat and the
first and last samples differ by about 0.002 in normalised amplitude. MP3 encoders add a short
priming delay, so a faint boundary may remain on a given player.

## Status

Technical checks only: the loop renders, decodes to non-silent samples and plays through the
actual production game in Chromium ([verification](FULLSCREEN_TRACING_AUDIO_VERIFICATION.md)).
Windows WebKit on this host does not support the tested native playback and has no AudioContext.
**Nobody has
auditioned it yet.** Teacher and pupil approval of its tone, level against the letter recordings
and its loop boundary is not recorded and must not be assumed. Audition it on the target phones
and tablets, and replace it by adding a new versioned file and updating `MUSIC_SOURCE` in
`src/audio/musicManager.js`; do not edit this file in place.

## Mix defaults (initial values to audition, not measured loudness)

- Music enabled by default; player volume 15%. Letter voice default 80%.
- Ready screens and countdown: about half the music level.
- While a letter recording plays: about 22% of the music level (roughly 3%).
- Music stops during pause, when the page is hidden or the app is backgrounded, and outside
  Jejak Ceria practice and challenge play. The teacher area has a separate on/off switch and volume.
